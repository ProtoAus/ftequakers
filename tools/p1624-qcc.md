# P1624 — standalone FTEQCC prerequisite

## Problem / change

Two compiler defects were reproduced without changing the game's source:

- `checkbuiltin()` inserted a call-only, uninitialized alias into the source name table. A subsequent call could miss its declared native builtin. Keep that alias non-referable; preserve checked-only deprecation suppression separately in the current, still-live scope.
- Generic control-flow optimization treated `BOUNDCHECK`'s literal b/c bounds as branch displacements. All three live generic walkers now skip that opcode. Runtime array bounds checking remains enabled.

This is compiler-only. No client signing feature, tournament code, new builtin/protocol, game rule, recorder, reader or recording schema is included. It is not a native client/server release or approval to overwrite a shared compiler.
